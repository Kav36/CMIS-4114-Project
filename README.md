# AI-Powered Q&A System - Quested

## Overview

This repository provides an AI-powered Question and Answer (Q&A) system that allows students to query course materials and receive accurate responses. The system utilizes a fully trained model hosted on Hugging Face, ensuring quick and efficient retrieval of relevant information.

## Accessing the Trained Model

The fully trained model is available on Hugging Face and can be accessed as follows:

   **Visit the Model Page**:  
   [Hugging Face Model Repository](https://huggingface.co/Kav36/quested)
