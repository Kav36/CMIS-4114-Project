# Project Setup and Installation Guide

This project involves running both a **Node.js** server and a **Python** backend. This README will guide you through the setup process for both environments and how to run the application.

---

## Prerequisites

Before proceeding, ensure you have the following installed on your system:

- **Node.js** and **npm** (Node.js package manager)
  - Install from [https://nodejs.org](https://nodejs.org)
  
- **Python** (Python 3.x)
  - Install from [https://www.python.org](https://www.python.org)
  
- **Tesseract** (for OCR functionality in Python)
  - Instructions for installation can be found below.
